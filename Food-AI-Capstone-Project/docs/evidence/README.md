# Browser evidence

Screenshots in this folder are from the local UI preview at `127.0.0.1:8002`. That preview used an isolated SQLite database because MySQL credentials were not configured. They demonstrate the interface only; use the verification report for the test and credential limitations.

- `menu-desktop.png`: catalog and cart at desktop width.
- `menu-mobile.png`: responsive catalog at mobile width.
- `orders-preview.png`: customer order history after a successful UI checkout.
- `swagger-api.png`: generated API documentation and endpoint list.
